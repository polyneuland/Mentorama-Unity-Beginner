# Mentorama-Unity-Beginner

Curso: **Profissão Desenvolvedor de Games em Unity**<br/>
Módulo: **Unity Iniciante**<br/>
Versão do Unity: **2020.2.6f1**

## Módulo 1
Primeira atividade do módulo:<br/>
Introdução e ambientação na ferramenta Unity: Hierarquia, cena e layout.<br/>
Os arquivos da cena podem ser encontrados em: [Module01](https://github.com/polyneuland/Mentorama-Unity-Beginner/tree/main/Files/Module01)<br/>
O objetivo principal foi transformar um cenário estático, o Template 3D Sample Scene (URP), em um ambiente interativo, aplicando conceitos fundamentais de simulação física para garantir realismo no comportamento dos objetos.

<img src="/Files/Module01/Sample.gif" alt="project"/>

## Módulo 2
Segunda atividade do módulo:<br/>
Trabalho com objetos na cena: Iluminação, câmera e prefab.<br/>
Os arquivos da cena podem ser encontrados em: [Module02](https://github.com/polyneuland/Mentorama-Unity-Beginner/tree/main/Files/Module02)<br/>
Assets: Pacote 3D por Academia Unity Desenvolvimento de Jogos - GameDev – YouTube<br/>
Este projeto foi desenvolvido com o objetivo de praticar os principais fundamentos de construção de cenas na Unity, com foco em iluminação, posicionamento de câmera e criação de prefabs.
